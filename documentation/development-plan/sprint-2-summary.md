## Sprint 3 Goals

In the Beta sprint, we look to refine our Alpha designs to provide a more frictionless user experience.

### Features

- Currently, a user is unable to see the details of recommended profiles besides a name and a similarity. We hope to add more interactivity there
- Require `first name` and `last initial` when user creates a profile to communicate some level of professionalism
- To prevent ethnicity based discriminations, obscure user last names
- Remove or optionalize hours available
- Permitting a user to change between FOUNDER and BUILDER after account creation
- Find alternative ways to represent users than a circle avatar with initials
- A map feature to pick locations as opposed to entering physical coordinates
